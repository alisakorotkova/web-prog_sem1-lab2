# Лабораторная 2 (Web-программирование) - ToDo List

_Короткова Алиса Александровна, 466293, поток Web 3.1_

My plans - личный планер, в котором можно записать задачу, выбрать день для ее выполнения и указать дедлайн.

[Открыть сайт](https://alisakorotkova.github.io/web-prog_sem1-lab2/)


## Возможности

- Создание, редактирование и удаление задач. Для новой задачи достаточно названия - описание, дату выполнения и дедлайн можно добавить по желанию.
- Отметка о выполнении и фильтрация задач по состоянию.
- Поиск по части названия и выбранной дате. Учитываются и дата выполнения, и дедлайн.
- Сортировка по дате выполнения или по дедлайну.
- Перетаскивание задач в режиме «Мой порядок». Порядок также можно менять стрелками ↑ и ↓ с клавиатуры.
- Сохранение задач и их порядка в `localStorage` между посещениями.
- Адаптивная верстка для компьютеров, планшетов и смартфонов.

## Технологии

HTML, CSS и JavaScript без фреймворков.
Интерфейс создается через DOM API. Для верстки используются Flexbox, Grid и медиазапросы.

## Структура проекта

- `index.html` - базовый каркас страницы и подключение скрипта.
- `css/style.css` - оформление планера и адаптивная верстка.
- `js/app.js` - создание интерфейса, работа с задачами и сохранение данных.
- `favicon.svg` - иконка вкладки браузера.

## Локальный запуск

Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server.
